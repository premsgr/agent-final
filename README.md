# Calculator

A tiny Python package providing `add` and `mul` functions.

## Installation

The package is tiny and can be used as a local module:

```bash
python -m pip install .
```

or simply copy `calc.py` into your project.

## Usage

```python
from calc import add, mul

print(add(2, 3))   # 5
print(mul(3, 4))   # 12
```

## Testing

Run the tests using `pytest` or `python -m unittest`.
